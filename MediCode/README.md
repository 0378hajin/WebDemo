# MediCode 웹 서비스 포트폴리오

건강검진 데이터와 유전자 분석 데이터를 결합해 질병 위험도를 계산하고, 사용자가 이해하기 쉬운 리포트로 제공하는 헬스케어 서비스입니다.

실무에서 개발한 ASP.NET Web Forms 화면과 데이터 처리 흐름을 이직용 포트폴리오로 재구성했습니다. 공개 저장소에 포함할 수 없는 실제 고객정보, 제휴업체 주소, 인증정보, 데이터베이스 연결정보 및 사내 프로시저 원문은 가상 JSON 데이터와 데모 로직으로 대체했습니다.

## 프로젝트 개요

MediCode는 사용자의 건강검진 결과와 유전자 분석 결과를 바탕으로 질환별 위험 수준을 계산하고, 보험 및 건강관리 관점에서 확인할 수 있도록 시각화하는 서비스입니다.

운영 환경에서는 여러 출처에서 전달받은 원천 데이터를 MS-SQL에 저장한 후 저장 프로시저에서 필요한 값을 계산합니다. 계산 결과는 ASP.NET Web Forms 화면으로 전달되며, 사용자는 질환별 상태와 건강검진·유전자 데이터의 반영 비율에 따른 결과 변화를 확인할 수 있습니다.

## 담당 업무

- 건강검진 및 유전자 데이터 연동 흐름 구현
- 외부 기관에서 전달된 데이터의 저장 및 화면 연계
- 유전자 분석권 번호를 이용한 유전자 분석 결과 조회 기능 개발
- MS-SQL 저장 프로시저를 통한 질환별 점수 및 위험등급 계산 연계
- 건강검진 데이터와 유전자 데이터의 보유 상태에 따른 화면 상태 관리
- 요약 리포트, 상세 리포트 및 질환별 결과 화면 구현
- 모바일 환경을 고려한 단계별 사용자 흐름 및 인터랙션 구현
- 포트폴리오 공개를 위한 개인정보·인증정보 제거와 정적 데모 구성

## 운영 환경의 데이터 연동 구조

### 1. 건강검진 데이터

건강검진 데이터는 사용자가 제휴 건강검진 데이터 제공기관에서 본인인증과 정보 제공 절차를 완료하면 전달됩니다.

```text
사용자
  ↓ 본인인증 및 정보 제공 동의
건강검진 데이터 제공기관
  ↓ 인증 완료 후 건강검진 결과 전송
MediCode 수신 및 저장 영역
  ↓
MS-SQL 저장 프로시저
  ↓ 질환별 점수·등급 계산
MediCode 리포트 화면
```

MediCode가 인증정보를 임의로 수집하는 방식이 아니라, 사용자가 외부 제공기관에서 인증을 완료한 이후 제공기관이 허용된 데이터만 전달하는 구조입니다. 수신한 데이터는 서비스에서 사용할 수 있는 형태로 정리한 뒤 위험도 계산에 활용합니다.

### 2. 유전자 분석 데이터

유전자 데이터는 사용자가 유전자 분석권을 구매하고, 제공받은 유전자 키트를 유전자 분석업체로 발송하는 과정에서 생성됩니다.

```text
유전자 분석권 구매
  ↓
유전자 키트 수령 및 검체 채취
  ↓
유전자 분석업체로 키트 발송
  ↓ 분석 완료 및 결과 데이터 생성
MediCode 연동 프로그램에서 분석권 번호 조회
  ↓ 유전자 분석업체 서버에서 결과 수신
MS-SQL 저장 및 프로시저 계산
  ↓
MediCode 정밀 리포트
```

이 과정에서 유전자 분석권 번호를 기준으로 제휴업체 서버에 분석 완료 여부와 결과 데이터를 조회하고, 조회된 값을 MediCode에서 처리할 수 있도록 연결하는 프로그램을 개발했습니다. 운영용 업체 주소, 요청 규격, 인증키, 분석권 번호 및 실제 응답 데이터는 보안과 계약상의 이유로 공개 대상에서 제외했습니다.

## 데이터 계산 및 화면 전달

건강검진과 유전자 원천 데이터는 MS-SQL 저장 프로시저에서 질환별 분석에 필요한 형태로 계산됩니다.

```text
건강검진 데이터 ─┐
                  ├─ MS-SQL 저장 프로시저 ─ 위험도 점수 및 등급 ─ Web Forms ─ 리포트
유전자 분석 데이터 ┘
```

저장 프로시저에서는 원천 데이터의 단순 조회뿐 아니라 항목별 값을 조합해 질환 위험도와 화면 표시용 결과를 계산합니다. 화면에서는 계산이 완료된 결과를 전달받아 `심각`, `위험`, `주의`, `양호` 상태와 상세 수치를 표현합니다.

## 포트폴리오 데모 시나리오

공개 데모는 외부 기관이나 운영 데이터베이스에 접속하지 않고 로컬 JSON만으로 동작합니다.

1. 서비스 시뮬레이터에서 MediCode 선택
2. 건강검진 데이터 불러오기
3. 건강검진 데이터만 반영된 기본 리포트 확인
4. 유전자 검사 데이터 불러오기
5. 건강검진과 유전자 데이터가 결합된 정밀 리포트 확인
6. 슬라이더를 움직여 데이터 반영 비율에 따른 결과 변화 확인
7. 질환별 상세 화면에서 분석 항목 확인

### 데이터 보유 상태에 따른 동작

- 건강검진 데이터만 존재: 리포트 슬라이더의 전체 범위를 건강검진 데이터로 사용
- 건강검진과 유전자 데이터 모두 존재: 슬라이더의 중심값을 기준으로 두 데이터의 반영 비율을 조절
- 슬라이더 변경: `data/report/0.json`부터 `data/report/10.json`까지의 가상 결과를 단계별로 표시

실제 운영 환경에서는 저장 프로시저 계산 결과를 사용하지만, 공개 데모에서는 동일한 화면 흐름을 설명할 수 있도록 미리 비식별화한 JSON 결과를 사용합니다.

## 기술 구성

- Backend: C#, ASP.NET Web Forms
- Database: MS-SQL, Stored Procedure
- Frontend: HTML5, CSS3, JavaScript, Vue.js 2.x
- Demo data: JSON, Session Storage
- Demo server: Node.js 기반 로컬 정적 서버

## 주요 화면

- `index.html`: 서비스 시뮬레이터 시작 화면
- `Intro.html`: MediCode 서비스 소개
- `Main_New.html`: 건강검진 및 유전자 데이터 로딩 상태 관리
- `Report.html`: 질환별 위험등급과 반영 비율 리포트
- `Report_Detail.html`: 선택한 질환의 상세 분석 결과
- `Disease_Plan.html`: 질환 관련 안내 화면
- `Health1.html`, `Health2.html`: 건강검진 데이터 연동 데모 단계

`source/WebForms` 폴더에는 데모로 정리한 ASP.NET Web Forms 구조를 함께 두어 정적 HTML 화면과 실제 프로젝트 구성을 비교할 수 있도록 했습니다.

## 실행 방법

JSON 데이터를 `fetch`로 읽기 때문에 HTML 파일을 직접 더블 클릭하지 않고 로컬 서버로 실행해야 합니다.

```text
node server.js
```

실행 후 브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:8080
```

서버는 외부 네트워크에 공개되지 않고 현재 PC의 루프백 주소에서만 실행됩니다.

## 공개 데모와 운영 환경의 차이

| 구분 | 운영 환경 | 공개 데모 |
|---|---|---|
| 건강검진 데이터 | 외부 제공기관 인증 완료 후 수신 | 가상 JSON 데이터 |
| 유전자 데이터 | 분석권 번호로 제휴업체 서버 조회 | 가상 분석 완료 데이터 |
| 데이터 저장 | MS-SQL | 정적 JSON 및 Session Storage |
| 위험도 계산 | 저장 프로시저 | 단계별 샘플 결과 |
| 사용자 정보 | 인증된 실제 사용자 | 포트폴리오용 가상 사용자 |
| 외부 통신 | 인증된 기관 및 업체 API | 외부 통신 없음 |

## 별도 유전자 조회 프로그램의 공개 범위

운영용 유전자 조회 프로그램 전체를 공개 저장소에 올리지는 않습니다. 대신 포트폴리오에서는 다음 범위만 재현하는 것이 안전합니다.

- 가상의 분석권 번호를 입력하는 조회 화면 또는 실행 예시
- `분석 대기 → 분석 완료 → 결과 수신` 상태 변화
- 업체 응답 형식을 단순화한 Mock JSON
- 인증 및 재시도 처리에 대한 구조 설명
- 실제 업체명을 제거한 인터페이스 또는 어댑터 코드

이를 통해 외부 시스템 연동 경험과 담당 범위는 보여주면서도 회사 자산, 제휴업체 규격과 민감한 유전자 데이터를 보호할 수 있습니다.
