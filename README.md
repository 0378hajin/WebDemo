# 금융·헬스케어 웹 서비스 포트폴리오

실무에서 개발한 MediCode와 VFA 화면 및 데이터 흐름을 개인정보와 운영 인증정보 없이 재구성한 정적 데모입니다.

## 폴더 구조

```text
WebDemo/
├─ index.aspx          # 프로젝트의 서비스 시뮬레이터 원본
├─ index.html          # 정적 데모용 서비스 시뮬레이터
├─ server.js           # localhost 전용 정적 서버
├─ portal/             # 최상위 서비스 시뮬레이터 리소스
├─ MediCode/           # 건강검진·유전자 분석 데모
└─ VFA/                # 변액보험 펀드관리 데모
```

## 실행

최상위 폴더에서 다음 명령어를 실행합니다.

```text
node server.js
```

브라우저에서 `http://127.0.0.1:8080`으로 접속합니다. JSON 데이터를 `fetch`로 읽기 때문에 HTML 파일을 직접 더블 클릭하지 않고 로컬 서버를 사용해야 합니다.

## MediCode

건강검진 제공기관의 인증 완료 후 전달되는 검진 데이터와 유전자 분석권 번호로 조회한 분석 데이터를 결합해 질환별 위험도를 제공하는 서비스입니다.

- 건강검진 데이터 불러오기
- 유전자 분석 데이터 불러오기
- SQL Server 저장 프로시저 계산 결과를 재현한 단계별 JSON
- 건강검진·유전자 반영 비율 조절
- 질환별 위험등급과 상세 리포트

상세 설명은 `MediCode/README.md`에서 확인할 수 있습니다.

## VFA

iM라이프 서비스 환경과 연계해 구축한 변액보험 펀드관리 흐름을 가상 회원·계약·상품 데이터로 재구성했습니다.

- 보험계약 및 현재 펀드 확인
- 투자 성향 기반 맞춤형 펀드 설정
- 추천 포트폴리오와 수익률 시뮬레이션
- 펀드 설정 및 리밸런싱 주기 변경
- 리밸런싱 전후 상세 내역
- 상품 추가 및 실 운영과 동일한 이용 가이드

## 공개 범위

- 실제 고객정보, 건강정보, 유전자 데이터 및 보험계약 미포함
- 운영 API 주소, 인증키, 쿠키 및 데이터베이스 연결정보 미포함
- 저장 프로시저 원문과 제휴업체 전용 요청 규격 미포함
- 사용자, 상품, 펀드, 금액과 수익률은 데모용 가상 값

## 상표 및 운영 서비스 안내

본 데모는 담당 기능과 협업 경험을 설명하기 위한 비식별화 포트폴리오입니다. iM라이프 관련 상표와 화면 요소의 권리는 해당 권리자에게 있으며, 본 데모는 iM라이프의 공식 서비스나 배포물이 아닙니다.
