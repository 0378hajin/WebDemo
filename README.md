# 금융·헬스케어 웹 서비스 포트폴리오

실무에서 개발한 AI Link, MediCode, VFA의 화면 및 데이터 흐름을 개인정보와 운영 인증정보 없이 재구성한 정적 데모입니다.

## 라이브 데모

- 포트폴리오: https://0378hajin.github.io/WebDemo/
- AI Link: https://0378hajin.github.io/WebDemo/AILink.html
- AI Link 실제 운영 서비스: https://www.ifa.co.kr/F000
- MediCode: https://0378hajin.github.io/WebDemo/MediCode/Intro.html
- VFA: https://0378hajin.github.io/WebDemo/VFA/Main.html

## 폴더 구조

```text
WebDemo/
├─ index.aspx          # 프로젝트의 서비스 시뮬레이터 원본
├─ index.html          # 이직용 포트폴리오 랜딩 페이지
├─ AILink.html         # AI Link 질문·응답 서비스 데모
├─ portal.html         # AI Link 호환 주소
├─ portfolio.css       # 랜딩 페이지 스타일
├─ server.js           # localhost 전용 정적 서버
├─ portal/             # 최상위 서비스 시뮬레이터 리소스
├─ MediCode/           # 건강검진·유전자 분석 데모
└─ VFA/                # 변액보험 펀드관리 데모
```

## 실행

최상위 폴더에서 다음 명령어를 실행합니다.

```text
node server.js
```

브라우저에서 `http://127.0.0.1:8080`으로 접속합니다. JSON 데이터를 `fetch`로 읽기 때문에 HTML 파일을 직접 더블 클릭하지 않고 로컬 서버를 사용해야 합니다.

## AI Link

사용자가 질문을 입력하고 AI 응답을 확인하며 관련 서비스를 탐색하는 대화형 서비스입니다. 담당 범위는 AI 모델이나 답변 생성 엔진이 아닌 프런트 화면과 사용자 상호작용 구현입니다.

- 질문 입력 및 응답 결과 화면 구성
- 대화형 UI 상태와 사용자 동선 구현
- AI 응답 데이터 표시
- MediCode와 VFA 등 관련 서비스 메뉴 연계

실제 운영 서비스는 iFA의 공식 서비스입니다. 본 포트폴리오는 담당한 프런트 화면과 사용자 상호작용을 설명하기 위한 별도 데모이며, 운영 서비스 전체 또는 AI 모델을 단독 개발했다는 의미가 아닙니다.

## MediCode

건강검진 제공기관의 인증 완료 후 전달되는 검진 데이터와 유전자 분석권 번호로 조회한 분석 데이터를 결합해 질환별 위험도를 제공하는 서비스입니다.

- 건강검진 데이터 불러오기
- 유전자 분석 데이터 불러오기
- MS-SQL 저장 프로시저 계산 결과를 재현한 단계별 JSON
- 건강검진·유전자 반영 비율 조절
- 질환별 위험등급과 상세 리포트

상세 설명은 `MediCode/README.md`에서 확인할 수 있습니다.

## VFA

iM라이프 서비스 환경과 연계해 구축한 변액보험 펀드관리 흐름을 가상 회원·계약·상품 데이터로 재구성했습니다.

- 보험계약 및 현재 펀드 확인
- 투자 성향 기반 맞춤형 펀드 설정
- 추천 포트폴리오와 수익률 시뮬레이션
- 펀드 설정 및 리밸런싱 주기 변경
- 리밸런싱 전후 상세 내역
- 상품 추가 및 실 운영과 동일한 이용 가이드

## 공개 범위

- 실제 고객정보, 건강정보, 유전자 데이터 및 보험계약 미포함
- 운영 API 주소, 인증키, 쿠키 및 데이터베이스 연결정보 미포함
- 저장 프로시저 원문과 제휴업체 전용 요청 규격 미포함
- 사용자, 상품, 펀드, 금액과 수익률은 데모용 가상 값

## 상표 및 운영 서비스 안내
